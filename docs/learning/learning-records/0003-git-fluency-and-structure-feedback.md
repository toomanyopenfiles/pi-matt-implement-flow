# 用户 git 基础现状与课程结构偏好（0002 v1 反馈）

0002 v1 被用户评为「完全没看懂」，检索练习靠蒙。反馈确认三件事：(1) 缺一张「谁、在何时、干什么、输入输出」的逐步表——流程叙事没有落成角色×步骤的矩阵；(2) 用户 git 命令不熟，命令、状态与流程的关系是困惑源；(3) 设计史/弯路叙事混在主线里，抬高了学习曲线。

## Evidence

- 用户逐条列出四点反馈（流程不清 / 要执行者×IO 表 / git 命令困惑 / 弯路叙事分散注意力）
- 排序练习「蒙了很多次」——排序项与讲解文本的措辞没有对齐

## Implications

- 后续课程模板：**先给「执行者 | 目标 | 输入→输出 | agent 归属」步骤表 + 角色着色流程图**，机制细节后置
- 假设 git 只懂 add/commit：任何命令首次出现配一句人话解释；已建 `reference/git-minimal.html` 跨课复用
- 设计史、探针故事一律放 `<details>` 折叠盒，标为可选阅读，不占主线注意力
- 0002 v2 已按此模板重排，待用户反馈验证模板是否成立
