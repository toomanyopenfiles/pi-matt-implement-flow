# Security Policy

## Supported Versions

Only the latest release of `pi-matt-implement-flow` (0.x) is supported with security fixes.

## Reporting a Vulnerability

Please report security vulnerabilities **privately** — do not open a public issue.

Preferred routes, in order:

1. **GitHub private vulnerability reporting**: the repository's **Security** tab →
   *Report a vulnerability* (creates a private security advisory).
2. **Email**: `blueswind830630@gmail.com` with the subject prefix `[SECURITY] pi-matt-implement-flow`.

Please include the affected version, the impact, and a reproduction if you have one.
I aim to acknowledge reports within 72 hours and to ship a fix or a mitigation plan
within a week of confirmation. Once a fix is released we can credit you in the advisory
and changelog, unless you prefer to stay anonymous.
